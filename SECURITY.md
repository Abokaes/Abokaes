# Security Policy

## Reporting Security Issues

We take the security of this project seriously.

If you discover a vulnerability or security flaw, please **do not** create a public issue or pull request.

Instead, please report security vulnerabilities through GitHub's Private Vulnerability Reporting mechanism:

1. Navigate to the **Security** tab of this repository.
2. Click on **Report a vulnerability**.
3. Fill out the details regarding the potential security issue.

Thank you for helping keep this project secure!
