# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security
vulnerability, please do NOT create a public issue.

Instead, please report security vulnerabilities privately using
[GitHub Private Vulnerability Reporting][pvr] via the **Security** tab of this
repository.

### Response Time

We aim to acknowledge reports within 48 hours and provide updates as fixes are
developed.

[pvr]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-communicating-a-vulnerability/privately-reporting-a-vulnerability
