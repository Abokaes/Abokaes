# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a
security vulnerability, please do NOT open a public GitHub issue or disclose it
publicly.

Instead, please report security vulnerabilities through GitHub Private
Vulnerability Reporting:

1. Navigate to the **Security** tab of this repository.
2. Click on **Report a vulnerability** under Vulnerability reporting.
3. Provide details about the vulnerability and steps to reproduce.

We will review your submission and respond as quickly as possible. Thank you for
helping keep this project secure!
