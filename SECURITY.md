# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please report it privately rather than opening a public issue.

Please report security vulnerabilities by navigating to the **Security** tab of this repository and selecting **"Report a vulnerability"** (GitHub Private Vulnerability Reporting).

### What to include in your report

- Description of the vulnerability and its potential impact
- Step-by-step instructions or proof-of-concept to reproduce the issue
- Any suggested remediations or mitigations

Thank you for helping keep this repository safe!
