# Security Policy

## Supported Versions

We actively support and fix security vulnerabilities in the latest stable
release of this repository.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.
Instead, report it responsibly by contacting us directly via email.

Please send your report to our security contact at
[Security Email][email-link].

We will investigate the report and respond as soon as possible. Please
include detailed steps to reproduce the issue so we can verify and fix
it quickly.
