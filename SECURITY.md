# Security Policy

## Reporting a Vulnerability

We take the security of this repository seriously.

If you believe you have found a security vulnerability, please do not report it publicly in an issue.

Instead, please report vulnerabilities privately using [GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/repository-security-advisories/configuring-private-vulnerability-reporting-for-a-repository) under the **Security** tab of this repository.

Thank you for helping keep this repository secure!
