# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within this repository, please report
it responsibly through GitHub Private Vulnerability Reporting via the Security
tab of this repository.

Please include as much detail as possible in your report:

* Type of issue (e.g., credential exposure, injection, XSS)
* Steps to reproduce the vulnerability
* Any proof-of-concept code or screenshots
* Expected impact of the issue

## Security Guidelines

* Do not commit sensitive tokens, secrets, or API keys to the repository.
* Ensure pull requests do not expose potential security vulnerabilities.
