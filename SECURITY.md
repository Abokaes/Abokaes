# Security Policy

## Reporting Vulnerabilities

We take the security of this repository seriously. If you discover a security
vulnerability, please do not disclose it publicly or open a public issue.

Instead, please report security vulnerabilities responsibly by contacting the
project maintainers directly or reporting via private vulnerability reporting
if enabled on GitHub.

### What to Include in Your Report

When reporting a vulnerability, please provide:

- A description of the issue and potential security impact.
- Detailed step-by-step instructions or proof-of-concept to reproduce the
  issue.
- Any suggested mitigations or fixes, if available.

### Preferred Response Times

We aim to acknowledge receipt of vulnerability reports within 48 hours and
provide status updates as we investigate and address reported issues.
