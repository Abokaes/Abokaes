## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not use the GitHub issue tracker. Instead, please report it through the GitHub repository's security advisory reporting tool if available, or contact the maintainer directly.

We take all security reports seriously and will work to address any issues as quickly as possible.
