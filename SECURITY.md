## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository,
please report it responsibly.

Do not report security vulnerabilities through public GitHub issues. Instead,
please submit security reports directly using **GitHub Private Vulnerability
Reporting** via the repository's
[Security tab](../../security/advisories/new).

When reporting a vulnerability, please include:

- A description of the issue and its potential impact.
- Detailed steps or proof-of-concept code to reproduce the issue.
- Any suggested mitigations or fixes.

We appreciate your efforts to keep this project safe and secure!
