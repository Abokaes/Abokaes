# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability within this repository,
please report it via GitHub Private Vulnerability Reporting:

1. Navigate to the **Security** tab of this repository.
2. Click on **Advisories** and then **Report a vulnerability**.

Please do not disclose vulnerabilities publicly in issues or pull requests.

Thank you for helping keep this project secure!
