# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found
a security vulnerability, please do not report it in a public issue or pull
request.

Instead, please report security vulnerabilities using
[GitHub Private Vulnerability Reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-communicating-a-vulnerability/reporting-a-vulnerability)
via the repository's **Security** tab.

Thank you for helping keep this project secure!
