# Security Policy

## Reporting a Vulnerability

We take the security of our project seriously. If you believe you have found
a security vulnerability, please report it responsibly.

Please report security vulnerabilities through GitHub Private Vulnerability
Reporting by navigating to the **Security** tab of this repository and
selecting **Report a vulnerability**.

### Disclosure Guidelines

- Do not create public GitHub issues for security vulnerabilities.
- Provide detailed steps to reproduce the issue.
- Give us reasonable time to investigate and address the report before any
  public disclosure.
