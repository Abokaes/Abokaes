# Security Policy

## Security Baseline

This repository adheres to security practices to safeguard data and assets.

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please report
it responsibly. Do NOT open a public GitHub issue for security vulnerabilities.

Please send an email detailing the vulnerability to:
[almlkb028@gmail.com](mailto:almlkb028@gmail.com)

### What to Include

- Description of the issue and potential impact
- Steps to reproduce the issue
- Any relevant logs, screenshots, or proof of concept code

We appreciate your efforts to responsibly disclose security vulnerabilities.
