## Reporting a Vulnerability

We take the security of this project seriously. If you discover or suspect a
security vulnerability, please do NOT report it publicly via GitHub issues.

### How to Report

Please report security issues privately using GitHub Private Vulnerability
Reporting on the repository's **Security** tab.

### Response & Handling Process

- **Acknowledgement:** We aim to acknowledge receipt within 48 hours.
- **Assessment:** We will validate and assess the reported vulnerability.
- **Resolution:** A fix or advisory will be prepared prior to public
  disclosure.

Thank you for helping keep this repository and its users safe!
