# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do not report it via public issues.

Instead, please report it through the following process:

1. **Email:** Please send an email to the repository owner.
2. **Details:** Include a detailed description of the vulnerability, steps to reproduce, and potential impact.
3. **Response:** We will acknowledge your report and work to address the issue as quickly as possible.

Thank you for helping keep this project secure!
