# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security
vulnerability, please do NOT create a public issue.

Instead, please report vulnerabilities directly through GitHub Private
Vulnerability Reporting via the **Security** tab of this repository.

### What to include in your report

- Description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Any suggested mitigations or fixes.

We appreciate your effort in responsibly disclosing security vulnerabilities.
