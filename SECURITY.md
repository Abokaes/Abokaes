# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security
vulnerability or risk, please report it responsibly.

### How to Report

Please report security issues through [GitHub Private Vulnerability
Reporting][pvr] via the Security tab of this repository.

Please do not open public issues or pull requests for security vulnerabilities.

### Response

We will acknowledge receipt of your vulnerability report within 48 hours and
provide updates as we work to address the issue.

[pvr]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-disclosing-vulnerabilities/privately-reporting-a-security-vulnerability
