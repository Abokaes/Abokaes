# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously.

If you discover a security vulnerability, please **DO NOT** open a public
issue. Instead, report it via GitHub Private Vulnerability Reporting:

1. Navigate to the **Security** tab of this repository on GitHub.
2. Click on **Report a vulnerability**.
3. Provide a detailed description of the issue and steps to reproduce.

Thank you for helping keep this project and its users secure!
