# Palette UX Journal

Welcome to Palette's UX journal. This journal is used to record critical UX
and accessibility learnings during profile README polishing tasks.

## 2026-07-30 - Initializing the UX Journal

**Learning:** Profile READMEs should adhere to high accessibility standards.
This includes wrapping all emojis in span elements with ARIA role="img" and
labels. Additionally, to avoid circular paths, Profile README files must avoid
links pointing back to the profile itself.

**Action:** Ensure all future Profile README enhancements feature properly
labeled emojis, no circular self-referential links, horizontal badge
alignments to reduce vertical clutter, and functional, non-violating "Back
to Top" scrolling anchors.
