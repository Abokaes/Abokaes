# Palette UX Journal

Welcome to Palette's UX journal. This space is used to record critical UX
and accessibility learnings during user interface improvements.

## 2026-08-06 - Initial Profile README Design

**Learning:** When building a GitHub Profile README, vertical spacing is easily
cluttered by vertical bullet lists of tech stack badges. Grouping them
horizontally improves layout. Similarly, adding right-aligned "Back to Top"
navigation anchors inside major sections improves scrolling fatigue.

**Action:** Organize tech stack badges horizontally using shields.io links
defined at the bottom of the document to keep lines within 80 characters.
Add right-aligned `<p align="right"><a href="#top">Back to Top</a></p>`
navigation anchors below major sections.
