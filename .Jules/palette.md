## 2026-07-07 - Structural Accessibility in Profile READMEs
**Learning:** GitHub Profile READMEs serve as the primary entry point for a user's digital identity. Using a top-level H1 heading and accessible emoji spans (<span role="img">) ensures that assistive technologies can correctly navigate and announce the profile's content, improving the first impression for all visitors.
**Action:** Always start README-based profiles with a single H1 and wrap emojis in ARIA-compliant spans.
