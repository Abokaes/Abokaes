## 2026-07-02 - Accessibility in Minimalist Repositories
**Learning:** In repositories where the README is the primary interface (like
GitHub Profile READMEs), structural accessibility (H1 for the first heading) and
the removal of "instructional placeholders" are critical for both screen readers
and visual "polish". A "finished" look without bracketed prompts or dangling
comments significantly improves the perceived quality and usability of the
profile for visitors.
**Action:** Always verify document structure with markdownlint and ensure all
template instructions or placeholders are replaced with high-quality content
before submission.
