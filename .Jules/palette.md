# Palette UX Journal

This journal tracks critical UX and accessibility learnings.

## 2026-07-14 - Initializing Palette Journal
**Learning:** Found that minimalist Profile READMEs often lack proper heading structure (MD041) and accessible emoji patterns, which are critical for screen reader users and SEO.
**Action:** Always start READMEs with a top-level H1 and wrap emojis in ARIA-compliant span tags.
