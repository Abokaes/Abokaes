# Palette UX Journal

A journal for recording critical UX and accessibility learnings in this
repository.

## 2026-07-24 - Interactive Badge Links and Friction Reduction in profile README

**Learning:** Static lists of badges or skills in profile documentation act as
pure decoration. Converting them into interactive, keyboard-navigable links to
official documentations provides immediately helpful context and a smoother UI/UX.
Furthermore, updating direct contact or feedback reference links to point
directly to specific action pages (such as `/issues/new` instead of `/issues`)
removes unnecessary click fatigue and cognitive friction, creating a more
intuitive user flow.

**Action:** Ensure tech stack badges are wrapped in helpful external reference
links, arranged horizontally to optimize vertical scanning space, and point user
feedback/contact buttons to direct creation endpoints. Always keep line lengths
under 80 characters.
