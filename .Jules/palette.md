# Palette UX Journal

This journal records critical UX and accessibility learnings discovered during
the development of this repository.

## 2026-07-12 - Initializing UX Standards

**Learning:** GitHub Profile READMEs often rely on default templates that use
incorrect heading levels (H2 instead of H1) and lack accessible emoji markup,
impacting screen reader users and structural clarity.

**Action:** Standardized the use of H1 headings for profile titles and wrapped
emojis in ARIA-labeled span tags to ensure a consistent and accessible first
impression.
