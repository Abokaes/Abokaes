## 2025-06-29 - Avoiding Hallucinated Personal Data in Profile READMEs
**Learning:** When populating user-facing profile templates, it is critical to avoid making assumptions about the user's personal details (e.g., LinkedIn, email, fun facts). Hallucinating these details can lead to misleading or unprofessional results.
**Action:** Always use generic, verified, or minimal placeholders, and prioritize links that use the repository owner's username for accuracy.
