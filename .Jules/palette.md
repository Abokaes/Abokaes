## 2026-06-20 - Emoji Accessibility in Markdown Headers
**Learning:** Emojis in GitHub Profile READMEs often lack semantic meaning for screen readers. Using H1 for the main profile title is also crucial for document structure.
**Action:** Always wrap emojis in `<span role="img" aria-label="description">` and ensure the main title uses a single `#` (H1) heading level.
