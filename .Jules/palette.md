# Palette UX Journal

A journal to record critical UX and accessibility learnings.

## 2026-08-08 - Accessible Anchoring and Responsive Layouts

**Learning:** When building highly navigable profile interfaces, adding "Back
to Top" anchor links below each section provides an immediate, low-friction
way to prevent scrolling fatigue on mobile and desktop viewports. To maintain
semantic standards, the target anchor should be placed within the H1 heading.

**Action:** Place a target span anchor inside the main H1 heading and provide
clear, accessible navigation links at the end of each section. Keep all lines
within the strict 80-character limit.
