# Sentinel's Security Journal 🛡️

## 2025-06-22 - Established Security Baseline
**Vulnerability:** Lack of security configuration files and unpinned GitHub Actions.
**Learning:** Even profile README repositories should have basic security measures like a `.gitignore` to prevent secret leaks and pinned actions to mitigate supply chain risks.
**Prevention:** Always initialize repositories with a `.gitignore`, `SECURITY.md`, and hardened GitHub Action workflows.
